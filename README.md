# 元素小课堂 · 手机离线版

安装网址：https://gaoxiaohui-commits.github.io/element-classroom-mobile/

跟氢氢一起，通过观察和操作探索五种元素：

- 氢：原版完整 8 站探险。
- 氦、锂、铍、硼：各 6 站全新探险，共 24 站；沿用氢课程的实验笔记、地图、角色对话、图鉴与星星反馈。
- 四元素总复习保留，并修正核素质量数与相对原子质量等表述。

氦包含浮力、光谱和低温任务；锂包含轻金属、电子与可逆充放电；铍包含选材、18 片太空镜和 X 射线窗口；硼包含玻璃、微量营养和材料应用。实验图为教学示意，非真实测量。

首次保持联网，等到“已可离线使用”。苹果使用 Safari 添加到主屏幕后，从桌面图标打开并注册；安卓使用 Chrome 安装。桌面版再次显示离线就绪后可断网使用。

已经安装旧版：联网打开并登录，看到“有新版本可用”后点“保存进度并更新”，再用原账号登录。账号、氢课程进度和原总复习进度继续保留。后四元素旧版的五关成绩和证书记录保留在各课程封面的“旧版学习记录”里；全新六站任务独立记录，从第一站开始。

账号和进度仅保存在当前设备的应用中，不上传服务器，不会自动跨设备同步。可从“账号与进度”导出加密备份。苹果 Safari 与桌面版可能使用不同存储；已有进度请先备份再恢复。

课程保存已完成关卡、星星、署名和设置；关卡中途离开后需从该关重新开始。顶部“课程目录”会等待进度保存成功后切换。旧单文件氢游戏的匿名存档不会自动并入某个账号。

本仓库仅包含可公开访问的静态发布文件，不含用户账号数据库或个人学习记录。
